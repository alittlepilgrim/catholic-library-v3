## Naming Key

- **Index / Glossary** — the printed book's own, transcribed; part of the original content. The only things that carry a `source:`.
- **Index Table of Contents** — built from the printed index; not original content; links into it.
- **List** — compiled pointers (terms, figures, places, works, feasts, anchors).
- **Vocabulary** — compiled definitions. Vocabulary : Glossary :: List : Index.
- **Cards** — the term/hub/figure/feast/place registry notes themselves.
- Single-letter suffix (`…-index-a`) — one letter of a printed index; navigate from its Index Table of Contents.
