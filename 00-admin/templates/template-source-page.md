# <% tp.file.title %>

A page of a source text — a chapter, an article, a section. The text itself goes here, as the source has it, with nothing paraphrased away.

**Three fields need a real answer before this note is finished:**

- `type:` — `bible`, `catechism`, `magisterium`, `doctor-work`, `theologian-work`, `reference-work`, `formation` or `legislation`
- `layer:` — `0` Scripture · `1` Magisterium · `2` a canonized author's own words · `3` scholarship about the tradition · `4` OCDS law
- `authority:` — `divine` · `magisterial` · `witness` · `scholarly` · `legislative`

If you are unsure between 2 and 3, the rule is authorship: a canonized author is layer 2, however scholarly the book; anyone writing *about* the tradition is layer 3, however devout. [[how-the-layers-work]] has the rest.

`part_of:` takes a quoted link to the work card — `part_of: "[[work-spiritual-canticle]]"`.
